# Archive

This directory preserves superseded implementations and exploratory workspaces.
Archived material is provenance, not an active dependency, and must not be
imported by new experiments.

| Path | Contents |
|---|---|
| `code/legacy-models/` | V1/V2 and earlier model implementations |
| `code/legacy-experiments/` | Experiment runners tied to legacy APIs |
| `paper/conference-workspace/` | Superseded drafts, exports, slides, build scripts, and Edition 1 work |
| `paper/legacy-generators/` | Earlier manuscript and figure generators |
| `prototypes/nscg/` | NSCG prototype and associated methodology document |
| `workbenches/model/` | Historical model exploration workspace and outputs |

Paths inside archived scripts may reflect their historical locations. No
runtime compatibility is promised. Archived payloads are excluded from the
public Git tree; this README documents the local lifecycle boundary only.
