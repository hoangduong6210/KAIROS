# Glossary

| Term | Meaning in this project |
|---|---|
| CFI | Model-derived index called the Causal Forecast Index in historical material; the name alone is not causal-identification evidence. |
| CSM | Differentiable five-state edge lifecycle mechanism: IDLE, BIRTH, REINFORCE, DECAY, DEATH. |
| RSE | Resonance Signal Encoder, the canonical model's edge-feature gating stage. |
| RMP | Resonance Message Passing, the canonical model's edge-message aggregation stage. |
| TIP | Temporal Information Parsimony, implemented as a stochastic variational bottleneck in the canonical forward path. |
| SCP | Symbolic Causal Policy, the prediction head whose name does not establish causal identification. |
| RS-GNN | Historical name for the KAIROS graph architecture. |
| VALIDATED | An artifact passed declared machine-verifiable gates. |
| ADMITTED | Exact scientific wording passed evidence and scope review. |
| BLOCKED | A named requirement prevents admission or progression. |
| QUARANTINED | Preserved but excluded from current scientific claims. |
| Evidence release | Immutable, checksummed artifact closure selected by `results/CURRENT`. |
| Paper snapshot | Immutable manuscript package locked to admitted claims and one evidence release. |
| Conference artifact | User-designated final conference file; distinct from an evidence-locked current paper snapshot. |
| Trace annotation | Section-level mapping from `C-*` or `H-*` claim identifiers to `E-*` evidence identifiers. |
