# Legacy result bundle

This directory contains the pre-restructure KAIROS JSON/TeX result artifacts.
They are quarantined historical records and support no current scientific
claim. `checksums.sha256` preserves their byte identity.

Do not edit these files in place or use them as the destination of a new run.
New mutable outputs belong under `runs/`; a claim-bearing release must be
created immutably under `results/frozen/<release-id>/` through the reviewed
evidence workflow.
