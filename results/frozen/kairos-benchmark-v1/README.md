# KAIROS benchmark v1 evidence release

This immutable release contains all declared model/seed attempts and their
aggregate metrics for the frozen benchmark-v1 protocol. Exact source,
configuration, protocol, data, result, coverage, and validation identities are
recorded in `release.json` and `checksums.sha256`.

The release supports only a within-dataset pseudo-label comparison. Scientific
interpretation and permitted wording are owned by the wiki result and claim
pages.
