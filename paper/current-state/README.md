# Current manuscript state

This directory is the living staging area for manuscript updates after the
conference submission. It currently contains no claim-bearing manuscript or
rendered paper.

Current scientific content is governed by the wiki and frozen evidence release
`kairos-benchmark-v1`. A future manuscript may be developed here only from
reviewed claim language and must be exported to a new immutable snapshot with
a `results.lock.yaml` before `paper/CURRENT` can select it.

The preserved conference submission is separate at
`paper/snapshots/kairos-conference-final/`. Never copy new benchmark wording
into, or otherwise modify, that historical snapshot.
